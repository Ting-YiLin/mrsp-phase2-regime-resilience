# Limitations and Do-Not-Claim List

## H&M
Frozen V1 H&M is a clean external replication attempt.
D28 was developed after seeing H&M evidence, so H&M D28 is not independent V2 validation.

## Grocery
D28 back-transfer is informative because 28 days originated in H&M and was not re-searched in grocery.
The grocery environment was nevertheless already studied.

## W54–W102
Do not claim later-time validation. Frozen CJ9 identity could not be reconstructed from public raw data.

## Promotion
Correct wording: available promotion / placement data did not establish promotion as the primary explanation; coverage and semantics prevented clean attribution.

## Do not claim
- universal 90% accuracy
- universal +9.5pp regime gain
- causal regime mechanism
- all produce categories benefit
- V1 is always better in stable periods
- binary gate beats D28
- signal count is a calibrated mixture weight
- D28=28 is universally optimal
- completed independent V2 external validation

Prefer two-cohort consistent patterns and pre-frozen thresholds over isolated maximum cells.

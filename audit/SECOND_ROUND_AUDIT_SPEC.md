# Second-Round Public Release Audit

After all platforms are live, a fresh reviewer checks the public surfaces rather than the build workspace.

## MUST check
1. GitHub public URL, repo tree, and file hashes.
2. Zenodo published status, DOI resolution, title, author, ORCID, rights, uploaded files.
3. SSRN submitted/public status, title, author, affiliation, abstract, AI disclosure, full-text PDF, and correct distinction between Submission ID and Abstract ID.
4. English article is authoritative; Traditional-Chinese version has no numerical or evidence-boundary drift.
5. Figures and tables match released CSVs.
6. No stale DOI/date placeholder tokens remain on public surfaces.
7. No overclaim: external validation, causal regime effect, universal 90%, universal +9.5pp, D28 universal optimum.

## Repair rule
Collect all material issues first. Perform ONE CONSOLIDATED REPAIR, then only targeted closure verification. Cosmetic wording is non-blocking unless it changes scientific meaning.

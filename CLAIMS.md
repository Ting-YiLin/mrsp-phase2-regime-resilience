# Public Claims and Evidence Boundaries


## C1 — Selective accuracy–coverage frontier
Frozen P1 thresholds create a reproducible grocery accuracy–coverage frontier:
all events ~60–62%; ~40% coverage ~78–79%; ~22% ~85–86%; ~11% ~90–91%.

## C2 — H&M exposes domain-shift / calibration limits
Frozen V1 selectivity remained in H&M, but old P1 coverage collapsed.

## C3 — D28 materially improves H&M development performance
Replacing cumulative market prior with D28 raised H&M accuracy from ~43.52% to ~50.07%.
This is development evidence, not independent V2 validation.

## C4 — D28 positively back-transfers to grocery
Without grocery window search:
- Representative: +0.89pp
- Department Challenge: +0.67pp

## C5 — D28 improvement is state-dependent
Average improvement materially understates rescue value because gains are concentrated in market-state transition strata.

## C6 — Three-signal regime is a strong descriptive rescue region
- Representative: +9.48pp D28 vs V1
- Department Challenge: +3.58pp
Coverage is only ~8–10%.

## C7 — High-shock threshold transfers directionally
A threshold frozen in Representative remained positively associated with D28 rescue in Department Challenge without retuning.

## C8 — Binary switching is not superior to all-D28
LOW_SHOCK→V1 / HIGH_SHOCK→D28 improves over V1 but does not outperform all-D28.

## C9 — Linear state weighting is not validated
Fixed signal-count weights did not robustly beat all-D28.

## C10 — P1 and Regime are different decision dimensions
P1 selects high-absolute-accuracy events.
Regime identifies history-fragility / rescue value.
Their gains cannot be arithmetically added.

## C11 — Promotion / merchandising is not established as the main mechanism
The available table is sparse and semantically selective. Promotion remains unresolved, not causally disproven.

## C12 — Later W54–W102 holdout is not valid from current provenance
Public raw data could not reproduce frozen CJ9 identity, so no clean later-time validation can be claimed.
